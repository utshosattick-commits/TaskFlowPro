TaskFlow Pro - PWA package

1. Upload THIS folder's contents to any HTTPS host (GitHub Pages, Netlify, Vercel, Cloudflare Pages).
   index.html, manifest.webmanifest, sw.js and the icons/ folder must sit together at the same level.
2. Open https://www.pwabuilder.com and paste your site's URL (e.g. https://yourname.github.io/taskflow/).
3. Click Start, then Package for stores -> Android -> Generate package.
   Download the zip: it contains the signed .apk (to install) and .aab (for Google Play).

PWABuilder reads a live URL; it cannot take a local folder.
